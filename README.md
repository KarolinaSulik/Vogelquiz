
# Vogelquiz 🐦

A simple iOS quiz application developed as part of my Computer Science studies.

## Technologies
- Swift
- SwiftUI
- MVVM architecture

## Features
- Bird species identification
- Two difficulty levels
- Interactive quiz interface

## About
This project was created to practice iOS development with SwiftUI and the MVVM architecture.
